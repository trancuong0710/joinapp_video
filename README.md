# Video Joiner Pro - Ứng dụng Ghép Nối Video MP4 Siêu Tốc (Offline)

Ứng dụng desktop hiện đại chạy trên Windows dùng để ghép nối nhiều video thành 1 file MP4 duy nhất, xử lý hoàn toàn offline trên máy tính mà không cần tải lên mạng.

---

## ⚡ Các chế độ nối video (Tối ưu tốc độ vượt trội)

1. **⚡ Ghép Siêu Tốc (Stream Copy - Mặc định & Khuyên dùng):**
   - **Tốc độ:** **Cực nhanh (100x - 300x)**, nối xong chỉ trong **vài giây** ngay cả với các video dài hàng giờ hoặc dung lượng nhiều GB!
   - **Chất lượng:** Giữ nguyên **100% độ sắc nét gốc** (do không giải mã và nén lại từng khung hình video).
   - **Âm thanh:** Vẫn hỗ trợ trích xuất và nối đúng **Audio Track** bạn đã chọn cho từng video.

2. **🚀 Mã Hóa Chuẩn Hóa (Tăng tốc phần cứng GPU):**
   - Dành cho trường hợp bạn muốn đổi độ phân giải (ví dụ: ép tất cả video về 1080p Full HD) hoặc các video có chuẩn nén khác nhau (VP9, HEVC, H264).
   - Tự động nhận diện và sử dụng bộ tăng tốc đồ họa phần cứng **GPU AMD (AMF)**, **NVIDIA (NVENC)**, **Intel (QSV)** hoặc **Windows Media Foundation**, giúp render nhanh gấp **5x - 10x** so với CPU thông thường.

---

## ✨ Tính năng nổi bật

- **Luôn xuất file MP4:** Tương thích 100% với mọi thiết bị, TV, điện thoại, trình duyệt và mạng xã hội.
- **Xem trước Thumbnail & Thông số:** Thời lượng, độ phân giải, FPS, dung lượng file, chuẩn nén.
- **Chọn Audio Track theo từng file:** Menu chọn audio track rõ ràng cho từng clip (tiếng Việt, tiếng Anh, thuyết minh, 5.1,...) hoặc tùy chọn tắt tiếng.
- **Kéo & Thả (Drag and Drop):** Kéo thả trực tiếp file hoặc cả thư mục video từ File Explorer vào ứng dụng.
- **Sắp xếp thứ tự clip:** Nút **▲ Lên** / **▼ Xuống** trực quan trên từng video.
- **Xem file ngay sau khi nối:** Nút mở xem video kết quả hoặc mở thư mục lưu chỉ với 1 click.

## 🚀 Cách khởi chạy ứng dụng

### Cách 1: Chạy file `.bat` (Khuyên dùng)
- Nhấp đúp chuột vào file **`run.bat`** trong thư mục `d:\joinapp_video`.

### Cách 2: Chạy bằng dòng lệnh Python
```bash
python main.py
```
